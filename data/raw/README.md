# Raw data — Malaga

Place your Inside Airbnb downloads here:

| File | Description |
|------|-------------|
| `listings.csv.gz` | Main listing features + **price** (target) |
| `reviews.csv.gz` | Review text (text modality) |
| `calendar.csv.gz` | Availability & nightly prices over time |
| `neighbourhoods.csv` | Neighbourhood names |
| `neighbourhoods.geojson` | Neighbourhood boundaries (spatial) |

Photo URLs are typically inside `listings.csv.gz` (`picture_url`, `thumbnail_url`).
